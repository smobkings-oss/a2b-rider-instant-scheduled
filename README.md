# A2B Rides - Rider App

Premium ride-hailing for NW Ohio. Instant and scheduled rides.

## Setup

1. `npm install`
2. Copy `.env.example` to `.env.local` and fill in keys
3. `npm run dev`

## Features (MVP)

- Instant ride requests
- Scheduled rides
- Map-based pickup/dropoff
- Realtime tracking (Supabase)
- Stripe payments
- Black/Gold/Holographic branding

## Tech Stack

- Next.js 15 + TypeScript + Tailwind
- Supabase (Auth, DB, Realtime)
- Stripe
- Capacitor for mobile (later)
